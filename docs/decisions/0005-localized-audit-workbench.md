# ADR 0005：产品壳采用双语审计工作台

- 状态：Accepted
- 日期：2026-07-30

## 背景

原 MVD 是中文三栏演示页，动态规则、IDS 和状态仍为英文，缺少运行历史入口，也没有稳定的语言或选择 URL。完整平台需要中英文主流程、可审计运行和窄屏可用性，但核心运行仍不能依赖 Node 或 CDN。

## 决策

保留无构建步骤的 HTML、CSS 和 ES module，采用单一 `i18n.json` 管理 `zh-CN` / `en` 对等键。URL `lang` 优先于本地保存值和浏览器首选语言；规则与构件选择也写入 URL。IFC 名称、schema 标识、属性路径和法规源文本保留源语言。

界面定位为高密度 BIM 审计工作台。证据链轨道是唯一显著的视觉签名；规则、3D、证据、结果、关系图和运行历史使用相同边界与数据字体，不添加无操作价值的统计卡。顶部持续展示“非审批、非认证、非法律意见”边界。

## 验证

- locale catalog 键集合、HTML/JavaScript 引用由自动化测试校验；
- 真实浏览器完成中英文切换、检查运行、历史刷新和稳定 URL 复验；
- 390×844 视口使用单列且无横向溢出；
- `prefers-reduced-motion` 和键盘可见焦点继续保留。

## 影响

这为后续 NL 查询、报告和设置页提供统一本地化契约。当前仍需为新增业务数据显式提供解释文本；不得把 IFC 源数据名称直接机器翻译后当成模型事实。
